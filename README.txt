DSphere Login Integration

1. Keep Login/index.html, login.css, login.js and logo.svg together.
2. Keep the stakeholder folder names exactly as supplied or update landingPage values in Login/login.js.
3. The stakeholder index.html files are placeholders. Preserve your existing dashboards and only merge the session integration block from each stakeholder JS file into your existing JS.
4. Run the HTTP server from the parent Dsphere folder: python -m http.server 8000
5. Open http://localhost:8000/Login/

Prototype credentials are listed in Login/login.js.
