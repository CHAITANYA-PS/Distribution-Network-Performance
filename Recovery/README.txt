Dsphere Recovery & Resolution Management - Complete Dashboards 1 to 9

Open index.html. Includes all visible internal tabs from the supplied wireframes, sample data, external CSS3, CSS-only charts, responsive layout and working navigation.

Validation file: js/validation.js

Included rules:
- Required inputs and minimum text length
- Positive currency/amount values
- Start/end date order, future due dates, non-future resolution dates
- File type and 5 MB size limit
- Investigation 5-Why completion
- Resolution checklist and decision validation
- Confirmation for save, submit, assignment, reopening and report actions
- Export prevention when no report data exists
- Inline accessible error messages

Investigation attachment is mandatory. Save Investigation is blocked until a valid file is selected.
